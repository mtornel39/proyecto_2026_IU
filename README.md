# proyecto_2026_IU

**PokéAprende** es la landing page de la Academia Ludus, desarrollada para el curso Interfaz de Usuario del IP Virginio Gómez.

Esta versión es la plantilla base del MVP: cada integrante desarrollará una parte a partir de ella.

## Secciones

| Sección | Enlace en `index.html` |
|---|---|
| Inicio | `#inicio` |
| Academia Ludus | `#academia` |
| Jugar Ahora | `#jugar` |
| Contacto | `#contacto` |

## Tecnologías

- HTML
- CSS
- Bootstrap 5
- JavaScript (validaciones con DOM)

## Estructura

```text
├── index.html
├── css/
│   └── estilos.css
└── js/
    └── app.js
```

## Cómo verlo

```bash
git clone https://github.com/mtornel39/proyecto_2026_IU.git
cd proyecto_2026_IU
```

Abre `index.html` en el navegador. Necesitas conexión a internet, porque Bootstrap se carga desde un CDN.
